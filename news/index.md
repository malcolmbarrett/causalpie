# Changelog

## causalpie 0.1.0

- Initial CRAN release.
- Added
  [`causify()`](https://malcolmbarrett.github.io/causalpie/reference/causes.md)
  and
  [`sc()`](https://malcolmbarrett.github.io/causalpie/reference/causes.md)
  for creating sufficient-component cause models.
- Added
  [`causal_pie()`](https://malcolmbarrett.github.io/causalpie/reference/pies.md)
  and
  [`causal_pie_necessary()`](https://malcolmbarrett.github.io/causalpie/reference/pies.md)
  for visualizing causal pies.
- Added
  [`components()`](https://malcolmbarrett.github.io/causalpie/reference/components.md),
  [`necessary_causes()`](https://malcolmbarrett.github.io/causalpie/reference/components.md),
  and
  [`sufficient_causes()`](https://malcolmbarrett.github.io/causalpie/reference/components.md)
  for querying cause data.
- Added
  [`theme_causal_pie()`](https://malcolmbarrett.github.io/causalpie/reference/themes.md)
  and
  [`theme_causal_pie_grid()`](https://malcolmbarrett.github.io/causalpie/reference/themes.md)
  for minimalist plot themes.
